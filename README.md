# Clash Royale Clone (Java) 🏰

An object-oriented implementation of the popular game Clash Royale, built in Java. This project demonstrates complex game mechanics, state management, and GUI development.

## 🚀 Features
- **Battle Field**: Dynamic battlefield rendering.
- **Deck Editor**: Interactive UI for players to build and manage their card decks.
- **Profile & Game History**: Track player profiles and previous game results.
- **UML Design**: Includes comprehensive class diagrams and project phase documentation.

## 🛠️ Tech Stack
- **Language**: Java
- **Architecture**: MVC pattern heavily reliant on Object-Oriented Principles.

## ⚙️ Getting Started
Open `ClashRoyale.iml` in IntelliJ IDEA, configure your JDK, and run the main application file.\n
